## 세션 시작 순서

1. **컨텍스트 탑재**
   - `.context/CURRENT.md` 정독
   - `.context/DECISIONS.md` 최근 항목 정독
   - `git status` + `git log --oneline -5`로 마지막 작업 히스토리 파악

2. **에이전트 피드백 확인** (Claude Code 환경)
   - `tasks/feedback-from-*.md` 파일 존재 시 내용 브리핑 → 적용 여부 질문

3. **Research Mode 노트 확인** (Research Mode 활성 시)
   - `.research/notes/`에서 `CURRENT.md`보다 최신 파일 확인
   - 새 노트 있으면 카테고리별 핵심 발견 브리핑 → 적용할 제안 선택 요청

4. **레슨 적용 확인**
   - `lessons/README.md`의 **태스크 매핑** 섹션에서 이번 세션 작업 유형을 찾는다
   - 해당 레슨 파일을 열람하고 체크리스트를 작업 계획에 반영한다
   - 예: 새 기능이면 05, 09 / 버그픽스면 01, 03, 04 중 해당 레슨

5. **브리핑 및 시작**
   - 한 문장 요약: "마지막으로 [X] 상태. [첫 번째 태스크] 시작합니다."
   - 바로 첫 번째 태스크 실행

---

자율 작업 원칙:
- 안전한 탐색/읽기 작업은 승인 없이 진행
- [분석 → 수정 → 검증] 흐름을 한 번에 묶어서 실행
- 실패 시 즉시 질문하지 않고 원인 파악 후 재시도 (최대 2회)
- 모호한 부분만 최소한으로 질문
